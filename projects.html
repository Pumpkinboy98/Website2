Projects

Project: Beginner to Advanced

1.

Interactive Command-Line Calculator

  • Difficulty: Beginner
  • Core Concepts: Input/output, variables, arithmetic operators, basic control flow (if/else).
  • Why It’s Worth Doing: It forces you to handle user input cleanly, validate edge cases (like preventing division by zero), and structure basic program loops without getting overwhelmed by complex logic.
2.

Number Guessing Game (with Difficulty & High Scores)

  • Difficulty: Beginner
  • Core Concepts: Random number generation, while loops, state tracking, basic file writing (saving scores).
  • Why It’s Worth Doing: You learn how to maintain game state across multiple turns and practice reading/writing data to a simple text file so scores persist after the program closes.
3.

Contact Book CLI App

  • Difficulty: Easy
  • Core Concepts: Data structures (arrays, lists, maps/dictionaries), CRUD operations (Create, Read, Update, Delete).
  • Why It’s Worth Doing: CRUD operations form the foundation of almost all real-world software applications. You'll learn how to search, update, and manipulate collection data efficiently in memory.
4.

Text-Based Inventory Management System

  • Difficulty: Easy–Intermediate
  • Core Concepts: Object-Oriented Programming (Classes, Objects, Encapsulation, Inheritance), file persistence (JSON or CSV).
  • Why It’s Worth Doing: This is the bridge where you move from procedural scripts to object-oriented design. You will model real-world entities (e.g., an Item class, an Inventory container class) and manage relationships between them.
5.

Flashcard Quiz CLI App with Spaced Repetition

  • Difficulty: Intermediate
  • Core Concepts: File parsing, custom algorithms, time/date manipulation, class inheritance.
  • Why It’s Worth Doing: Instead of just testing memory, implementing a basic spaced-repetition algorithm (asking harder cards more frequently) teaches you how to translate logic and rules into algorithmic code.
6.

Command-Line To-Do Manager with Sorting & Search

  • Difficulty: Intermediate
  • Core Concepts: Abstract Data Types (Queue, Stack), custom sorting algorithms (Bubble Sort, Merge Sort), CLI argument parsing.
  • Why It’s Worth Doing: Rather than relying entirely on built-in language tools, writing your own logic to sort tasks by priority or due date builds a deep understanding of basic data structures and algorithmic complexity ($O(n)$ vs $O(n \log n)$).
7.

Markdown to HTML File Converter

  • Difficulty: Intermediate–Advanced
  • Core Concepts: String manipulation, regular expressions (Regex), file I/O streams, edge-case parsing.
  • Why It’s Worth Doing: Text parsing is a fundamental computer science concept. Building a converter teaches you how compilers interpret plain text and transform it into another formatted language.
8.

Custom Banking & Account Management System

  • Difficulty: Advanced
  • Core Concepts: Advanced OOP (Polymorphism, Interfaces/Abstract Classes), error handling/exceptions, transaction history logging.
  • Why It’s Worth Doing: Financial systems require strict data validation, secure state management, and clear class hierarchies (e.g., SavingsAccount and CheckingAccount inheriting from Account). It teaches you how to write robust, bug-resistant code.
9.

Command-Line Chat Application (Socket Programming)

  • Difficulty: Advanced
  • Core Concepts: Client-Server architecture, TCP sockets, multithreading/concurrency, network protocols.
  • Why It’s Worth Doing: CS degrees place heavy emphasis on systems and networking. Building a socket-based chat app forces you to handle asynchronous data streams and multi-user synchronization.
10.

Expression Evaluator & Math Parser (AST Generator)

  • Difficulty: Capstone / Advanced
  • Core Concepts: Stack data structures, Tokenization, Parsing, Abstract Syntax Trees (AST), Recursion.
  • Why It’s Worth Doing: This takes a mathematical expression like (3 + 5) * 2 as a string and evaluates it properly using operator precedence. It combines nearly every core CS concept—recursion, stacks, trees, and parsing—giving you a massive head start on university-level Data Structures and Algorithms.
